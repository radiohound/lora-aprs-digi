LoRa APRS Digi Setup

Connect the digipeater with its USB cable, read its settings, change them in a form and save. Nothing leaves this page.

Not connected.

This browser has no Web Serial. Use Chrome or Edge on a computer (not a phone), and open this page over https or from a saved file.

Radio settings (frequency, bandwidth, spreading factor) and the key are not here. Use the terminal for those.

All other settings

Everything the digipeater has, built from what it reports. Only the boxes you change are sent. Changing a radio setting (frequency, bandwidth, spreading factor and so on) applies it to the radio before saving. A radio setting the chip refuses is not saved.

The chip ID is the key for over-the-air commands. Paste it into the remote page. It is only printed at start-up, so the digipeater restarts. Saved settings are kept.
