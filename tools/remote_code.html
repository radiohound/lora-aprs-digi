LoRa APRS Digi Remote

Makes a command for a LoRa APRS digipeater. Send the result as an APRS message to the digi. Nothing leaves this page.

How it works

The message is counter command code. The counter is this device's clock in seconds; the digi only accepts a counter higher than the last one it took, so a recorded message cannot be sent again. The code is SipHash-2-4, keyed with the digi's chip ID or your secret, over CALLSIGN|counter|command: it proves the command came from someone holding the key, and the key never goes on the air.

Over the air: get, set, save, beacon, reboot. The callsign, the radio settings and the secret can only be changed on the digi's serial port. A change works at once and is kept after save.
